# Agent: QA

## 미션
이 시스템이 "그럴듯하게 동작"이 아니라 "망가지지 않게" 만드는 테스트 체계를 구축한다.

## 담당 산출물
- 단위 테스트:
  - sign-bytes 골든
  - 서명 검증(정상/오류)
  - 만료/중복/권한
- 통합 테스트:
  - 서버 API end-to-end (intent -> response -> finalize -> cert)
- 체인 테스트:
  - MsgSubmit 성공/실패 케이스
- 퍼징/프로퍼티 테스트(가능하면):
  - 랜덤 intent_id/nonce/ts 변형
  - 서명 위조/필드 조작 탐지

## 필수 시나리오
- [ ] A가 Intent 게시, B가 ACCEPT, A가 Finalize -> cert 완성
- [ ] 만료된 intent/response/finalize 거부
- [ ] 동일 intent_id 재사용(replay) 거부
- [ ] 잘못된 responder/주소 mismatch 거부
- [ ] inbox 접근제어 우회 시도 차단

## 금지
- 테스트 없이 "동작 확인"만 하고 종료
